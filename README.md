A lightweight envelope-style budgeting app for tracking monthly income, assigning spending categories, and seeing how much money remains after expenses.

## Description

Envelope Budgeter helps users organize their budget using the envelope method: assign portions of income to categories like rent, food, utilities, and entertainment, then calculate whether they are over or under budget.

This project is built as a simple front-end web app using HTML, CSS, and JavaScript, making it easy to run locally or deploy to GitHub Pages.

## Live Demo

Visit the app here:

https://yamkelamazwi.github.io/Envelope-Budgeter/

## Features

- Enter total monthly income
- Add and track spending categories
- Calculate remaining budget
- See whether the total is over budget or has surplus remaining
- Clean, responsive interface
- Built with vanilla HTML, CSS, and JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yamkelamazwi/Envelope-Budgeter.git
   ```
2. Open `index.html` in a browser, or serve the project with a local web server.
